# 🕉️ GSEB ધોરણ 10 સંસ્કૃત – સંસ્કૃત સાધના (Sanskrit Std 10 Web Application)

## 📖 પ્રોજેક્ટ પરિચય (Project Overview)
**સંસ્કૃત સાધના** એ ગુજરાત માધ્યમિક અને ઉચ્ચતર માધ્યમિક શિક્ષણ બોર્ડ (GSEB) ધોરણ 10 ના વિદ્યાર્થીઓ અને સંસ્કૃત વિષયના શિક્ષકો માટે ખાસ તૈયાર કરાયેલી **હાઈ-પર્ફોર્મન્સ, AMOLED Dark Mode સિંગલ-પેજ વેબ એપ્લિકેશન (SPA)** છે.

આ એપ્લિકેશનમાં કોઈ પણ પ્રકારની બિનજરૂરી માહિતી કે સ્કૂલ એડમિન ફ્લફ વિના, **સંપૂર્ણપણે બોર્ડ પરીક્ષાલક્ષી અધ્યયન સામગ્રી (100% Curriculum & Exam Focused)** નો સમાવેશ કરવામાં આવ્યો છે. તમામ વિશ્લેષણ, સૂચનાઓ અને અનુવાદ શુદ્ધ ગુજરાતી ભાષામાં છે, જ્યારે તમામ શ્લોકો, વ્યાકરણ પદો અને શબ્દરૂપો શુદ્ધ સંસ્કૃત (દેવનાગરી લિપિ) માં પ્રસ્તુત કરેલા છે.

## ✨ મુખ્ય વિશેષતાઓ (Key Features)

### ૧. વ્યાકરણ મોડ્યુલ (Grammar Engine)
બોર્ડ પરીક્ષામાં પૂછાતા તમામ વ્યાકરણ વિષયો માટે ૪ વિશિષ્ટ ટેબ્સ:
* **ટેબ ૧: શોર્ટકટ ટ્રીક (Shortcut Tricks):** પરીક્ષામાં પ્રત્યય ઓળખવાની સચોટ ફોર્મ્યુલા અને ચાવીઓ.
* **ટેબ ૨: કોષ્ટકો (Interactive Tables with Neon Gold Highlighting):**
  - **૫ સંપૂર્ણ નામરૂપ વિભક્તિ કોષ્ટકો:**
    1. **રામ (અકારાન્ત પુલ્લિંગ)** – પ્રથમા થી સપ્તમી + સંબોધન
    2. **વન (અકારાન્ત નપુસકલિંગ)** – પ્રથમા થી સપ્તમી + સંબોધન
    3. **લતા (આકારાન્ત સ્ત્રીલિંગ)** – પ્રથમા થી સપ્તમી + સંબોધન
    4. **ભૂમિ (હ્રસ્વ ઇકારાન્ત સ્ત્રીલિંગ)** – પ્રથમા થી સપ્તમી + સંબોધન
    5. **નદી (દીર્ઘ ઈકારાન્ત સ્ત્રીલિંગ)** – પ્રથમા થી સપ્તમી + સંબોધન
  - પ્રત્યેક પ્રત્યય (જેમ કે `-ः`, `-म्`, `-ण`, `-य`, `-त्`, `-स्य`, `-भ्याम्`, `-भ्यः`, `-नाम्`, `-षु`) ને વિશિષ્ટ **Neon Gold Glow (`.suffix-hl`)** થી હાઇલાઇટ કરેલ છે જેથી યાદ રાખવું અત્યંત સરળ બને.
  - સરળ નેવિગેશન માટે **હોરિઝોન્ટલ ટેબલ સિલેક્ટર ચિપ્સ (Table Switcher)**.
  - **કાળ અને ધાતુરૂપ કોષ્ટકો:** વર્તમાનકાળ, સામાન્ય ભવિષ્યકાળ, હ્યસ્તન ભૂતકાળ (પરસ્મૈપદ અને આત્મનેપદ).
  - **કૃદંત પ્રત્યયો કોષ્ટક:** સંબંધક, હેત્વર્થ, કર્મણિ, વિદ્યર્થ, કર્તરિ કૃદંત.
* **ટેબ ૩: ઉદાહરણો:** સંસ્કૃત વાક્યો અને ગુજરાતી અનુવાદ સાથે પરીક્ષાલક્ષી વિશ્લેષણ.
* **ટેબ ૪: MCQ ટેસ્ટ:** ત્વરિત સાચા/ખોટા ઉત્તર, વિગતવાર સમજૂતી અને સ્કોર.

### ૨. પદ્ય વિભાગ (Poetry & Shlokas)
અભ્યાસક્રમના તમામ ૭ પદ્ય પ્રકરણો:
* પ્રકરણ ૧: **સંવદધ્વમ્** (ऋग्वेद संज्ञान सूक्त)
* પ્રકરણ ૪: **જનાર્દનસ્ય પશ્ચિમઃ સંદેશઃ** (મહાકવિ ભાસ)
* પ્રકરણ ૭: **સુભાષિતકુસુમમંજરી** (નીતિ સુભાષિતો)
* પ્રકરણ ૧૦: **ત્વમેકા ભવાની** (આદિ શંકરાચાર્ય સ્તોત્ર)
* પ્રકરણ ૧૩: **ગીતામૃતમ્** (શ્રીમદ્ ભગવદ્ ગીતા શ્લોકો)
* પ્રકરણ ૧૬: **અદ્ભુતં યુદ્ધમ્** (વાલ્મીકિ રામાયણ - જટાયુ પરાક્રમ)
* પ્રકરણ ૨૦: **તથેવ તિષ્ઠતિ** (કર્ણભારમ્ / સુભાષિતો)

દરેક પ્રકરણમાં:
1. પ્રસ્તાવના અને કથાસાર
2. સંસ્કૃત શ્લોક અને સ્ટેપ-બાય-સ્ટેપ ગુજરાતી અનુવાદ
3. અઘરા સંસ્કૃત શબ્દોનો ગુજરાતી અર્થકોશ (શબ્દાર્થ)
4. બોર્ડ પરીક્ષાના મોસ્ટ IMP પ્રશ્નોત્તરી

### ૩. ગદ્ય & નાટ્ય વિભાગ (Prose & Drama)
અભ્યાસક્રમના તમામ ૧૩ ગદ્ય અને નાટ્ય પાઠો:
* પ્રકરણ ૨: **યદ્ભવિષ્યતિ વિનશ્યતિ** (પંચતંત્ર વાર્તા)
* પ્રકરણ ૩: **સ્વસ્થવૃત્તં સમાચર** (આયુર્વેદ દિનચર્યા)
* પ્રકરણ ૫: **ગુણવતી કન્યા** (દશકુમારચરિતમ્)
* પ્રકરણ ૬: **કાષ્ઠખંડઃ** (સંસાર સાગરના ૪ વિઘ્નો)
* પ્રકરણ ૮: **સાક્ષીભૂતઃ મનુષ્યઃ** (અકસ્માતના ૩ કર્તવ્યો)
* પ્રકરણ ૯: **ચક્ષુષ્માન્ અંધ એવ** (હર્ષચરિતમ્ - ક્રોધના દુષ્પરિણામ)
* પ્રકરણ ૧૧: **યસ્ય જનનં તસ્ય મરણમ્** (કૂટનાથ અને વિત્તદાસ)
* પ્રકરણ ૧૨: **કલિકાલસર્વજ્ઞઃ હેમચંદ્રાચાર્યઃ** (સિદ્ધહેમ શબ્દાનુશાસન)
* પ્રકરણ ૧૪: **કઃ ઇદમ્ દુષ્કરં કુર્યાત્** (ચાણક્ય અને ચંદનદાસ)
* પ્રકરણ ૧૫: **જયઃ પરાજયો વા** (આધુનિક યુદ્ધના પરિણામો)
* પ્રકરણ ૧૭: **સ્વાભાવિકં સાદૃશ્યમ્** (પતંજલિ મહાભાષ્ય સાદૃશ્ય નિયમ)
* પ્રકરણ ૧૮: **મુક્તાનિ મુક્તકાનિ** (પ્રહેલિકાઓ અને રમૂજી સુભાષિતો)
* પ્રકરણ ૧૯: **સત્યં મયૂરઃ** (ભગવદજ્જુકિયમ્ પ્રહસન)

### ૪. Auto Quiz Maker & Custom MCQ Generator
* **Auto Quiz Maker:** પ્રશ્નોને રેન્ડમ ક્રમમાં શફલ કરીને નવો ક્વિઝ સેટ તૈયાર કરે છે.
* **નવો MCQ ઉમેરો (Add Your Own MCQ):** શિક્ષકો કે વિદ્યાર્થીઓ પોતાના નવા પ્રશ્નો, ૪ વિકલ્પો, સાચો ઉત્તર અને સમજૂતી ઉમેરી શકે છે. આ ડેટા બ્રાઉઝરના `LocalStorage` માં સુરક્ષિત સેવ થાય છે.

### ૫. UI/UX ડિઝાઇન
* **AMOLED Dark Mode:** બેકગ્રાઉન્ડ `#0a0f1d`, કાર્ડ્સ `#161f36`, ગોલ્ડ એક્સેન્ટ `#fbbf24`.
* **મોબાઇલ-ફર્સ્ટ ડિસ્પ્લે:** 480px મહત્તમ પહોળાઈ સાથે સેન્ટર્ડ સ્લીક એપ ડિઝાઇન.
* **ફોન્ટ સાઈઝ નિયંત્રણ (A±):** સંસ્કૃત શ્લોકો અને કોષ્ટકો સરળતાથી વાંચવા માટે એક ક્લિકમાં ફોન્ટ સાઈઝ વધારવા/ઘટાડવાની સુવિધા.
* **સ્ટીકી હેડર & લાઈવ સર્ચ:** કોઈપણ પ્રકરણ કે વ્યાકરણ મુદ્દો ત્વરિત શોધવા માટે સર્ચ બાર અને બેક બટન (`← પાછા જાઓ`).

## 🛠️ ટેક્નોલોજી સ્ટેક (Tech Stack)
* **Frontend:** શુદ્ધ HTML5, CSS3, Vanilla Modern JavaScript (ES6+).
* **Typography:** `Noto Sans Devanagari` (સંસ્કૃત માટે), `Noto Sans Gujarati` (ગુજરાતી માટે), `Mukta`.
* **ડિપેન્ડન્સી:** શૂન્ય બાહ્ય ફ્રેમવર્ક (Zero Dependencies) – અતિશય હળવું અને ક્ષણભરમાં લોડ થતું.
* **ડેટા સંગ્રહ:** HTML/JS ઇનલાઇન ડેટાબેઝ + LocalStorage (કસ્ટમ MCQs માટે).

## 🚀 પ્રોજેક્ટ કેવી રીતે ચલાવવો (How to Run Locally)

### રીત ૧: સીધું બ્રાઉઝરમાં ખોલો
કોઈપણ વધારાના ટૂલ કે સોફ્ટવેર વગર:
```bash
# ફાઇલ પર ડબલ ક્લિક કરો અથવા બ્રાઉઝરમાં ઓપન કરો:
index.html
```

### રીત ૨: લોકલ સર્વર વડે (Vite / Node.js)
```bash
# ડિપેન્ડન્સી ઇન્સ્ટોલ કરો (જો ડેવલપમેન્ટ ટૂલ્સ વાપરવા હોય તો)
npm install

# લોકલ ડેવલપમેન્ટ સર્વર શરૂ કરો
npm run dev

# પ્રોડક્શન બિલ્ડ તૈયાર કરો
npm run build
```

3. **ઓફલાઇન સુવિધા:** ઇન્ટરનેટ કનેક્શન ન હોય ત્યારે પણ એકવાર લોડ થયા પછી એપ અસ્ખલિત ચાલે છે.
